# tokenbroke

**Are you tokenbroke? Prove it.**

```bash
npx tokenbroke
```

Reads your real local Codex CLI / Claude Code usage — two numbers: usage % and reset time,
never your code, never your prompts — and files you anonymously on the public leaderboard of
the most rate-limited developers alive: **https://tokenbroke.lol**

- ~5 seconds, no signup. Re-run any time to update your row.
- `npx tokenbroke hooks install` — optional: auto-refile quietly after your coding sessions. Remove with `hooks remove`.
- Claim your row (GitHub, optional) with the printed link if vanity wins.

One small command for a dev — one giant leap for devkind.

Unaffiliated parody & community tool. Not endorsed by OpenAI or Anthropic. The bit is
affectionate; the data is serious.
