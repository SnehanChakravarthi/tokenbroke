# Security

tokenbroke's CLI reads files on developers' machines, so security reports take priority over
everything else in this repo.

If you find a vulnerability — especially anything that could make the CLI read or transmit more
than usage/rate-limit state — please report it privately:

- GitHub: use **"Report a vulnerability"** under this repository's Security tab, or
- X: DM [@theteknosaur](https://x.com/theteknosaur).

Please don't open a public issue for a security problem until a fix is out. Reports are typically
acknowledged within a couple of days.
